# Visual Sinalização — Obras

Aplicação web estática para pesquisa e conferência de logradouros, com atalhos para GeoSampa, Dicionário de Ruas, Busca CEP e Google Maps.

## Publicação com GitHub Pages

1. Crie um repositório chamado `visual-sinalizacao`.
2. Envie `index.html`, `README.md` e `.nojekyll` para a raiz da branch `main`.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)` e clique em **Save**.
6. Aguarde a publicação e abra o endereço mostrado na página de configurações do GitHub Pages.

## Observações

- O site é estático e não precisa de etapa de build.
- O mapa incorporado é uma referência visual da cidade de São Paulo.
- Os atalhos abrem as consultas nos portais externos.
- A consulta cadastral automática do GeoSampa ainda precisa de integração própria; não considerar campos sem confirmação como dados oficiais.
- O site publicado pelo GitHub Pages fica acessível publicamente. Não coloque informações internas ou dados pessoais neste repositório.
